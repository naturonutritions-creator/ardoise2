Dépose ici les fichiers audio enregistrés (voix réelle) pour chaque son de
phonétique CP. Format accepté : .mp3 ou .m4a. Nom de fichier = code du son.

Fichiers attendus (22) :
ch.mp3, an.mp3, in.mp3, oi.mp3, gn.mp3, ill.mp3, j.mp3, ss.mp3, c.mp3,
er.mp3, b.mp3, p.mp3, t.mp3, d.mp3, m.mp3, l.mp3, n.mp3, r.mp3, f.mp3,
v.mp3, oin.mp3, ien.mp3, ai.mp3

Chaque clip doit contenir UNIQUEMENT le son, prononcé une fois, dans un
fichier séparé (pas un seul fichier avec les 22 sons à la suite : le site
ne peut pas découper automatiquement un enregistrement continu).

Tant qu'un fichier n'existe pas, le bouton "Écoute la vraie prononciation"
ne s'affiche pas sur la leçon correspondante (repli silencieux) : la leçon
utilise alors la synthèse vocale du navigateur comme avant.
